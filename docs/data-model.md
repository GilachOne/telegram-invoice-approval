# Структура реестра

Сопоставление прочитано из блока записи основного сценария. Режим — «Добавить запись», начало поиска — строка 2. Имена переменных сохранены, значения и ссылки на рабочие таблицы исключены.

| Колонка | Источник | Назначение |
|---|---|---|
| A | Идентификатор (`id`) | Системный идентификатор, выбранный в блоке; уникальность для каждой заявки не проверялась |
| B | `Счет` | Переданный документ или ссылка |
| C | `Сумма` | Сумма платежа |
| D | `плательщик` | Юридическое лицо плательщика |
| E | `Контрагент` | Получатель платежа |
| F | `Дата отчета` | В пользовательской инструкции — крайний срок оплаты |
| G | `Тип РК` | Выбранный тип расходов |
| H | `Источник` | Выбранный источник |
| I | `Направление` | Направление расходов |
| J | `бюджет` | Подтверждение бюджетного контекста |
| K | `Name` | Имя инициатора |
| L | `telegram_id` | Идентификатор инициатора в Telegram |
| M | `Дата и время запуска в систему` | Время подачи |
| N | `Комментарии к расходам` | Распределение по проектам и месяцам |

Лист «Акты» использует отдельную запись:

| Колонка | Источник | Назначение |
|---|---|---|
| A | Идентификатор (`id`) | Системное поле блока |
| B | `id_payment` | ID платежа, к которому относится акт |
| C | `payment_proof` | Файл подписанного акта |

Проверка существования платежа, уникальности связи и автоматическая сверка актов с реестром при осмотре не подтверждены.
