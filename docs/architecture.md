# Архитектура

| Компонент | Ответственность | Что изучено |
|---|---|---|
| Telegram | Ввод данных и документов, опрос направления, получение уведомлений | Настройки блоков в Leadteh |
| Leadteh | Диалог, переменные, проверка ввода, переходы между сценариями | Основной сценарий и сценарий актов |
| JavaScript в Leadteh | Формирование текста уведомления из переменных | Код блока подготовки подписи |
| Google Sheets | Реестр заявок и отдельный лист актов | Режим записи и сопоставление колонок |
| Внешний HTTP-сервис | Приём документа и подписи для передачи в Telegram | Настройки POST; реализация сервера не изучалась |

## Передача документа

В HTTP-блоке настроены POST, `multipart/form-data` и таймаут 85 секунд.

| Поле | Значение по конфигурации |
|---|---|
| `chat_id` | Идентификатор целевого чата, скрыт в публичном кейсе |
| `caption` | Переменная `ТГ_сообщение` |
| `parse_mode` | `HTML` |
| `document` | Переменная `Счет2` |

Переменная `Счет` используется в реестре и подписи, `Счет2` — в HTTP-передаче документа. Механизм получения `Счет2` здесь не реконструируется.

## Важные границы

- Telegram-опрос в изученном сценарии предназначен для выбора направления; его нельзя выдавать за подтверждённую реализацию голосования согласующих.
- Текст «Нет ответа от сервера» на схеме является названием выхода HTTP-блока, а не доказательством текущего сбоя.
- Текст «Записи не найдены» является выходом блока Google Sheets, а не результатом выполненного запроса в ходе осмотра.
- Бюджет подтверждается прикреплённым материалом и пояснениями. Автоматический расчёт остатка бюджета не подтверждён.
- Документы и решения об оплате не отправлялись при подготовке портфолио.
